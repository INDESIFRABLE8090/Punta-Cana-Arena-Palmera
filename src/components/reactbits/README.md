# React Bits

Componentes copiados sin modificar de [React Bits](https://github.com/DavidHDev/react-bits)
(variante `ts-default`), que es como la librería se distribuye: no es un paquete npm.

| Componente | Uso en el sitio |
|---|---|
| `SplitText` | Titulares de sección que entran palabra a palabra (`SplitHeading.astro`) |
| `Magnet` | Botones principales que siguen al cursor en escritorio |
| `ShinyText` | Rótulo dorado de la sección Transporte |
| `Waves` | Fondo de líneas en movimiento de la sección Transporte |
